# Scored by: mechanical checks (grounding, structure) + editor read (thesis,
# Persian). Every point must cite the failing line on a miss.

1. Honesty (2 pts): every number traces to evidence; scenario conditional
   ("اگر...") never stated as fact; no point prediction disguised as analysis.
   - 2 = clean; 1 = one soft spot (e.g. conditional stated once as likely);
   0 = any fabricated number or presented-as-fact forecast.
2. Thesis (2 pts): one backbone; all numbers serve it; ends naming who bears
   costs. 2 = undeniable spine; 1 = wanders once; 0 = list of facts.
3. Scenario logic (2 pts): the "if" is explicit with a trigger level; the
   chain from trigger to consequence names each step; no skipped links.
   2 = airtight; 1 = one fuzzy link; 0 = jumps from if to doom.
4. Persian (2 pts): rule-13 clean (<=25-word sentences, no doubled به‌عنوان,
   no colloquialisms, one-line parens max); flows aloud. 2 = publish-ready;
   1 = 1-2 rough spots; 0 = P43-style run-ons.
5. Attribution (1 pt): source+year once per metric, never repeated, full list
   in Sources. 1 = clean; 0 = any repeat or missing source.
6. Hook (1 pt): dated anchor opening per frozen style, reader feels stakes in
   2 lines. 1 = hooked; 0 = throat-clearing.
